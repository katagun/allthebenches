Captured 18 October 2026 at 14:22 UTC from the public [Mistral Large 4 model page](https://artificialanalysis.ai/models/mistral-large-4). The serialized page contains a `models` collection and a separate `currentModel` object. The adapter includes the latter when it is not already in the collection, maps exact normalized release slugs only, preserves the AA model ID, and records field-level locators.

The raw Next.js flight capture is identified by SHA-256 `accc9bc3f737a8c91e178abe2e9d90eb9ef2671670d1fc8a4dee14785700e14d`. This hash identifies the captured bytes; it is not an independent reproduction of the evaluations. AA documents a [keyed API](https://artificialanalysis.ai/api-reference), but this staging uses its public page serialization, which is not a stable API contract. No API key was requested or used. Attribution is retained in the fragment; reuse terms for the page data were not established (`license: null`).

## Coverage accounting

The capture contained 704 provider model records. Exact normalized release matching found 67 records across 29 of the 45 canonical releases. Sixteen canonical releases had no exact record in this capture: Qwen-AgentWorld-35B-A3B, Qwen3-30B-A3B-Base, Qwen3-14B-Base, Qwen3-8B-Base, DeepSeek-V3-Base, DeepSeek-R1-Distill-Qwen-7B, Claude 3.5 Sonnet (June 2024), Gemini 1.5 Pro (May 2024 report checkpoint), Gemini 1.5 Flash (May 2024 report checkpoint), Llama 3.1 8B Instruct, Llama 3.1 70B Instruct, Llama 3.1 405B Instruct, Mistral 7B, Mixtral 8x7B, DeepSeek V4 Pro 0813, and Dots3-Note Preview. This means no captured match, not a zero score or confirmed non-evaluation. New source-specific configurations are candidate mappings; they preserve explicit AA effort labels and do not infer effort from token counts or names.

Staging contains 1,082 candidate observations across 30 metric variants (five existing exact variants and 25 new AA variants), 1,082 independent AA series, and 66 deterministic AA-specific configurations (54 explicit effort settings and 12 configurations with absent effort left unknown). Source-specific configuration IDs keep resolution stable if another feed later adds a configuration with the same generic effort label. Explicit `none` and `non-reasoning` labels map to disabled mode; explicit `default` labels map to default mode. No reasoning token count is converted into an effort label. The standalone fragment passes `merge_fragments` schema validation, has no ID conflicts with curated data, and can be merged idempotently. No result is promoted to reviewed in this fragment.

## Exclusions and unresolved coverage

- `intelligenceIndex` is omitted for all 11 matched rows where `intelligenceIndexIsEstimated` is true. Their direct component results remain eligible independently.
- `gdpvalNormalized` is not staged alongside `gdpval`: it is a duplicate normalization, `(Elo − 500) / 2000`, of the same GDPval result.
- `briefcaseTotalCost`, `intelligenceIndexTimePerTask`, price/cache fields, token counts, context-window sizes, and model-parameter fields are not benchmark scores. In particular, AA per-task cost is not a whole-run evaluation cost.
- Numeric `LiveCodeBench` results are retained as their own pass@1 series, but the page field has no problem range/version. Do not merge them with another LiveCodeBench release without resolving that setting.
- AA’s source fields `tau2` and `tauBanking` are kept as separate Telecom and Banking benchmark series. Historical index membership does not make these rows comparable with current AA index metrics.
- No observation is generated for a missing/null field, an unmatched release slug, or a row without an exact or explicitly unknown configuration. Absence from this page snapshot does not mean that a model was evaluated and scored zero.

The [documented API](https://artificialanalysis.ai/api-reference) requires an API key, which was not available or requested. The public snapshot is therefore a bounded point-in-time extraction rather than a recurring collection contract.
